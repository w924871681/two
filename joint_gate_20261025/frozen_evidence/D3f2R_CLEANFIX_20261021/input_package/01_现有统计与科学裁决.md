**原 STABILITY_PASS 的含义**：在旧研究提前锁定的经验风险约束下，Joint 优于合格且活跃的最强新强门控基线 MWU-Mean，且中心级配对区间支持。这**不是**“Joint 对所有基线都有显著更低原始 MSE”的证明。5% 是经验约束，不是统计分布保证。

**未覆盖范围**：原 CMC Fig.3/7/8 使用 Always-FT、ER、EWC、Huber-FT、ValidationCommit、Frozen；这批比较尚未用 Joint 的新配置在同一独立评估池全量重跑。旧 Fig.3—8 的统计不能直接与 Joint 新结果拼接。

**研究目标**：整体算法的风险—效用优势及论文完整方法贡献。无强制每个组件独立显著性要求；但不能因单纯合并已有统计量就无证据宣称全新理论机制。最终论文必须区分风险合格优势、原始 MSE 全方法优势和泛化。

**统计解释**：原配对 Bootstrap 95%区间未做逐基线 family-wise 多重比较校正。最终须完整报告全部比较和定义 primary contrast，不可把支持性区间一概称为多重校正的统计显著。
