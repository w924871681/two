**主要成功裁决** `FINAL_MAIN_PASS`：Joint活跃且逐流风险合格；在**全部11项事先冻结的对照基线**中，逐一按相同的三流经验风险资格和clean/mixed实际提交资格筛选出合格且活跃者，以其中**平衡MSE最低者**为全局主要对照（包含原论文六基线和原RAVM版本，而不是仅三项强门控）。Joint相对该全局最优合格活跃基线主MSE相对改善≥0.2%，中心级配对95%区间上界<0，改善中心≥17/32，维护成本比≤2.5，才可MAIN_PASS。不得因为某个原论文基线比MWU更强就将其排除。若没有合格活跃对照、存在缺失实现或必要科学记录，则不可签发MAIN_PASS，应停为INCONCLUSIVE或预检STOP。风险不合格的RecentMean等仍需完整报告MSE和风险，但**不要求新方法对每个风险不合格基线都显著降低原始MSE**；此外全面对照区间并未进行多重比较校正，不得宣称family-wise显著。
