# D3f2R Smoke→Final：V2主比较口径更正（必须在数据生成前冻结）

## 更正理由

用户认可的最终目标是**风险合格前提下的生命周期效用—风险优势**，不是对所有基线的原始MSE都统计显著。V1 JSON 将Final主成功叙述为优于最强“风险合格强门控”，而其Prompt又要求如果原CMC基线更强则不能宣称全体成功；两处存在潜在解释歧义。现统一为唯一机械判据，防止跑完12臂后挑对照。

## V2明确最终主成功判据

- Final固定12臂，其中新Joint为候选、剩余11臂均为待检比较者。
- 从**全部11个基线**中挑选`clean/mixed至少一次真实commit`且`clean/mixed/coherent逐流harm≤5%及downside≤固定限制`的**全部风险合格活跃比较者**。
- 取其中在同一个全新Final池上`center等权clean/mixed平衡MSE最低`的一臂作为**全局最强合格活跃对照**；如不存在，`FINAL_MAIN_INCONCLUSIVE`。
- Joint必须自己逐流风险合格、实际更新，并相对该最强对照有预锁≥0.2%的MSE改善、配对中心bootstrap95%上界<0、至少17/32中心改善、同口径维护成本比≤2.5，独立审计VALIDATED，才签发`FINAL_MAIN_PASS`。
- 对其余10个比较者逐项列出MSE、逐流风险、成本、配对区间。高效用但风险不合格方法（如可能的RecentMean）**不要求**其原始MSE显著差于Joint，但必须如实描述效用—风险取舍。
- 仅通过一项对观察后选出的全局最优对照的点估计与普通bootstrap区间，**不能**声称已对所有11种比较完成多重比较校正的显著性检验。全部区间和选择口径必须公开。
