# Public field-data descriptive check

Source: Wang2025, Scientific Data12:1481, DOI10.1038/s41597-025-05825-9. Dataset DOI10.6084/m9.figshare.27147678.v3, CC BY4.0. Original filenames (including hosptial spelling), CSV bytes and notebook retained, provider MD5/size and SHA checks in receipt. No article PDF is redistributed.

Run `python profile_readonly.py --output NEW_OUTPUT_DIRECTORY` with Python/pandas. It verifies the attached bytes and reconstructs all three released-row/temperature-label counts, without optimization. Hourly state labels are not measurement-error ground truth or fault-event incidence. See R24_PUBLIC_EVIDENCE_ZH.md before interpreting percentages.
