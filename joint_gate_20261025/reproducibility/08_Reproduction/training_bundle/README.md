# Submission reproduction attachment

The submission attachment 06_Reproducibility_Materials.zip contains aggregate reconstruction for Main/E0-E5 and the two descriptive field profiles. Its training_bundle includes five unchanged synthetic group configurations, all their referenced processed inputs and frozen source/M0 weights, original engine code, and twenty exact source prefixes. They support the sixteen previously accepted synthetic PATH_A cases (twelve Main methods, three architecture/horizon cases and one cost case), plus the specified matching synthetic PATH_B. The earlier nineteen-case acceptance also covered Alibaba, UCI and ThermBuild; those three external input/checkpoint paths are NOT self-contained in this submission attachment. Their provider acquisition/recipe descriptions and result aggregates remain supplied, not an assertion that the measured-domain input/weight bytes are attached.

All model/array bytes included here match their existing accepted copies. Full frozen group input references are retained so the existing launcher need not alter frozen group definitions. This is not all-domain or full-matrix independent replication. No candidate trajectories, failed-run weights, raw Alibaba/building archives, font libraries or author-home paths are included. This packaging task performs no optimizer update. External interpreter/runtime installation remains a prerequisite.
