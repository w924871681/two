# Final editable Joint Gate framework figure

`fig2_joint_gate_final.svg` is editable native vector artwork (text, shapes,
paths); `draw_fig2.py` is the complete standalone generation source. No input
image is read or embedded. The author-confirmed raster and original design
reference are retained separately in the local intake archive.

Run `python draw_fig2.py` with the optional packages in requirements.txt.
The checked drawing runtime was Python 3.13.5, Matplotlib 3.10.0, PyMuPDF
1.27.2.3 and Pillow 12.3.0. Arial must be locally available; no fonts are
distributed. No datasets, checkpoints or research directory are needed.
This is an artwork build and performs zero training or scientific computation.

The PDF is 468 x 278 points (165.1 x 98.07 mm) with zero raster objects.
The RGB TIFF is rendered directly from native vectors at 1200 dpi,
7800 x 4634 pixels; it is not an enlarged source bitmap.

FIG2_CONNECTIONS.json lists every scientific arrow and its temporal role.
P and Q denote the parent and candidate. Both losses use the same current
Verification windows. The mean uses paired loss differences; one-sided MWU
compares the two loss samples. Bars, sample dots and curves are schematic.
The green state denotes the selected identity, not established safety.
Only the deployed model state advances along the dashed next-stage loop.
Service is retrospective after identities/action are sealed. Eligible matured
data may be used in later Update intervals under the original temporal protocol;
this does not permit current Service labels to enter the current gate.

OpenAI Codex (client 0.163.0-alpha.11) assisted explicit figure-code preparation;
Matplotlib rendered the artwork. The original raster is not the publication
asset. The complete manuscript source uses the vector PDF directly.
