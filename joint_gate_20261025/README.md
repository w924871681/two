# Joint Gate revision — CMC manuscript and experiment artifacts

This directory contains the current 25 October 2026 Joint Gate manuscript revision,
its source, final figures, and the research results and reproduction materials
published at the author's request on 27 October 2026. The repository's earlier
RAVM-DT version and its existing release remain available separately.

## Contents

- `paper/`: Clean, Tracked, response and supplementary PDFs; complete
  `LaTeX_Source.zip`; and the three reviewer/editor-specific response PDFs.
- `figures/`: the eight PDF figures used by the final Clean manuscript. The
  regenerated experimental figures 3–8 are also supplied as SVG and PNG;
  Figure 2 additionally has editable SVG and a TIFF.
- `reproducibility/05_Scientific_Traceability/data/`: the supplied Main and
  E1–E5 summary tables and trajectory-level aggregate CSVs, including negative
  findings. These are aggregates, not all raw per-stage model trajectories.
- `reproducibility/07_Figure_Source/`: `redraw_figures.py` and its frozen CSV
  input list; `fig2_vector_final/draw_fig2.py` generates the Figure 2 artwork.
- `reproducibility/08_Reproduction/`: read-only result reconstruction, public
  field-data descriptions and the supplied synthetic training subset, code,
  configurations, checkpoints and instructions. See its README and REPRODUCE.md.
- `frozen_evidence/`: available frozen scientific and engineering source,
  configuration, summary reports and audit receipts from the manuscript baseline.

The `reproducibility/` directory contains every member of the supplied
reproduction ZIP, with its original SHA-256 member manifest. It is distributed
as individual repository files because the original ZIP exceeds GitHub's
100 MiB single-file limit. `paper/LaTeX_Source.zip` is provided unchanged.

## Read-only verification and plots

With the packages listed in `08_Reproduction/requirements-readonly.txt`, run
from `joint_gate_20261025/reproducibility/`:

```bash
python 08_Reproduction/reconstruct_readonly.py
python 07_Figure_Source/redraw_figures.py
```

These commands write reconstructed outputs and figures, but do not train any
model. On the recorded local environment, aggregate reconstruction passed and
regenerated Figures 3–8 matched the final manuscript figures pixel for pixel;
different fonts and library versions may render differently. See
`PUBLICATION_VERIFICATION.json`. The six figure SVG/PNG files in `figures/`
were regenerated by this script using the supplied frozen CSVs.

## Interpretation, access and provenance

The Main comparison reports 4.85% lower balanced lifecycle MSE than the selected
empirically risk-qualified active DualMean baseline and improvement in 29/32
centers. The RecentMean comparison interval crosses zero. The manuscript retains
the E1 severe-mixed, E2 H4, E3 external-utility, E4 thermal risk, and E5 cost
limitations. These are empirical results, not a formal future safety guarantee.

The supplied reproduction subset covers sixteen synthetic PATH_A cases and one
specified staged PATH_B, not all domains, all matrix entries or independently
verified external full training. No Alibaba, UCI or ThermBuild processed training
inputs/checkpoints are included in this subset. Third-party notices and access
conditions remain in `reproducibility/LICENSES_AND_ACCESS.md` and alongside the
relevant data. Large per-stage model archives and external raw datasets are not
redistributed. No additional experiment or training was performed for this upload.

The original attachment's statements that publication was not yet authorized
describe its pre-publication status; the subsequent author request authorized
this GitHub publication. They are retained verbatim for provenance. Three historic
engineering/provenance copies replace the local Windows username with
`LOCAL_USER`; see `PUBLICATION_PATH_REDACTIONS.json` for original and public
hashes. Scientific formulas, parameters, data and results were not changed.
Historic scripts may require their recorded original environment and local paths;
the supplied read-only entry points are separate from those old run scripts.

Verify this snapshot with `python verify_files.py` from this directory.
